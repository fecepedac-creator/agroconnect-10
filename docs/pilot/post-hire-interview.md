# Entrevista posterior a la contratacion

Registrar respuestas sin datos sensibles innecesarios.

## Trabajador

1. Del 1 al 5, que tan facil fue postular?
2. Entendiste lugar, pago, horario y transporte antes de postular?
3. La oferta coincidio con el trabajo real?
4. Pudiste contactar a la empresa sin ayuda?
5. Que paso te resulto confuso?

## Empresa

1. Cuanto tiempo paso desde publicar hasta el primer candidato util?
2. El perfil entrego informacion suficiente para decidir?
3. Cuantos contactos terminaron en entrevista y contratacion?
4. Que dato faltaba para tomar una decision?
5. Pagarias una suscripcion por repetir este resultado?

## Metricas asociadas

- Tiempo a primera postulacion.
- Tiempo a match.
- Porcentaje match/contacto.
- Porcentaje contacto/contratacion.
- Ofertas con condiciones completas.
- Incidentes y solicitudes de soporte por proceso.
