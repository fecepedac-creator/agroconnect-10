# Quality Gates (Skill Acceptance)

## Gate 1: Trigger Clarity

- Frontmatter description includes explicit triggers.
- Scope and non-scope are explicit.

## Gate 2: Actionability

- Workflow is executable without hidden assumptions.
- Commands include real paths and required tools.

## Gate 3: Safety

- Security-sensitive operations include safeguards and rollback.
- No secrets or credentials embedded.

## Gate 4: Verification

- Skill defines observable outputs (diff, report, checklist).
- Includes minimum validation step.

## Gate 5: Maintainability

- No duplicated long references inside SKILL.md.
- Detailed content moved to references files.
- File names and sections are predictable.

## Definition of Done

A skill is accepted only when all five gates pass and at least one real task has been executed with it.
